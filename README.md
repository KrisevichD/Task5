# Task 5 - React JavaScript Practice

## Features
#### Catalog page -> /catalog
- Retrieves category & products lists using RTK Query     
- Manages the state of the cart slice (Redux toolkit)
#### Product page -> /catalog/:id
- Retrieves product info using RTK Query
- Manages the state of the cart slice (Redux toolkit)
#### Cart page -> /cart
- Manages the state of the cart slice (Redux toolkit)

#### other
- /config folder stores Webpack settings
- routing is configured using React-router
- modular styles

## How to run app
#### npm i
> installs the dependencies to the local node_modules folder

#### npm run start 
> starts local devServer in development mode

#### npm run build / npm run build:prod
> create build in development/production modes
